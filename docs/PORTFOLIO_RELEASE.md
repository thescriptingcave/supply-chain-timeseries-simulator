# Portfolio Release Notes

This repository is a cleaned Supply Chain-only portfolio release derived from a larger local IoT simulation workspace.

Excluded intentionally:

- Solar generator and telemetry code
- Refinery generator and telemetry code
- Legacy multi-domain live streamer
- Development archives and temporary ZIP packages
- `.env` and local credentials
- `.git` history from the source workspace
- Python caches and editor/OS artifacts

The Supply Chain V3 simulation behavior is preserved. Packaging changes focus on repository scope, bootstrap SQL, public configuration, documentation, and presentation.
